# Prakhar Khedekar — Portfolio

Editorial personal site for [Prakhar Khedekar](https://github.com/coderkhede) (`coderkhede`).

## Stack

- Next.js 14 (App Router, TypeScript)
- Tailwind CSS
- Framer Motion
- Lucide React

## Run

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Content

All copy, projects, timeline, and social URLs live in `src/data/portfolio.ts`. Update email, Twitter, and resume details there.

Portrait source: `photo/my_image.jpeg` → copied into `public/images/`.
